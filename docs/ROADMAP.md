## Routines and song moments (track R, planned 20 Oct 2026)
Its own numbering so it doesn't clash with the station tasks above. Start each session with: "Read docs/ROADMAP.md and do task R1." Firmware-repo tasks are marked; they read this file too.

**Words.** An **animation** is one short named light pattern (e.g. "Engine"). A **section** is a slot in a routine that plays one animation: **Start-up**, **Ambient** (was "standard"), **Beat** (Pulse: music it doesn't know) and **Song moments** (Pulse: a part of a song it recognises). A **routine** is the whole thing: one animation per section plus a **colour set**. The code's "phase" becomes "section", and "recognition" (the plug-in hello) is renamed so it isn't confused with song moments.

**The idea: a player.** Today each animation is hand-written code, and both chips are full (Pulse routine 13,192 of 13,248 bytes, Core 4,006 of 4,096). Instead, each drive gets one small **player** that knows a handful of moves (glow, breathe, wave plug→logo, flash, twinkle, flicker, fill, colour drift), and an animation becomes a short recipe of layers, e.g. "breathe, all LEDs, colour 1, 4 s" + "wave up, colour 2, every 2 bars": tens of bytes, not hundreds. Recipes say colour 1/2/3, never "red", so any animation works with any colour set; the existing Pulse sets (lagoon, lagoon_deep, ultraviolet, glacier, sunset, neon, original) carry over (slot red → colour 1, orange → 2, white → 3). The app's preview runs the same player, so the preview is what the drive does. Animations are made by describing them to Claude in a Claude Code session: Claude writes the recipe and shows a preview; no API key. Core drives get re-initialised once (Jonny: OK).

**Animation ideas** (Ambient especially): Drift (today's Core flow), Breathe, Heartbeat (the plug-in one), Idle rev (an engine ticking over, follows "Engine"), Tide (glow rises plug→logo and sinks), Comet (a point travels up and fades), Drip (falls logo→plug), Ember (warm random flicker), Twinkle (dim base, odd sparkles), Lava (two colour blobs drift and merge), Lighthouse (one section at a time), Aurora (slow colour waves front to back, needs the LED positions). Each with a speed (seconds, or bars on Pulse) and a direction.
